# ЛР № 1: многомерная оптимизация генетическим алгоритмом

**НИЯУ МИФИ, Б24-507, номер по списку 15.** Формула из методички: `V=1+((17·15+7·0+26) mod 20)=2`. Вариант 2 — 7-мерная функция Розенброка на `[-5,10]^7`.

## Установка и запуск

Нужен Python 3.10+.

```bash
python -m pip install -r requirements.txt
python main.py --runs 20 --seed 2026 --out results
python -m unittest discover -s tests
```

Опционально: `--evaluations 40000 --population 100`. Бюджет должен делиться на размер популяции, размер популяции не меньше 30. По условию `--runs` не меньше 20. Запуск перезаписывает файлы в `results/` и формирует `REPORT.md` рядом с `main.py`.

## Что реализовано

- Вещественная популяция размером 100, турнирная селекция (k=3), BLX-α (α=0.5), покоординатная гауссовская мутация, отсечение границ, 2 элитные особи.
- Расписание масштаба мутации σ от 0.7 до 0.025.
- По 20 независимых запусков для p=0.20, p=0.40 и случайного поиска при одном и том же бюджете 40 000 фитнес-оценок.
- В `results/runs.csv` индивидуальные решения с seed; в `convergence.csv` траектории по поколениям (и эквивалентный бюджет оценок) min/mean/max; `stats.json` содержит статистику, парный t-тест и лучшую особь; `experiment_config.json` сохраняет параметры; `convergence.png` и `boxplot.png` — графики; `flowchart.png` — блок-схема алгоритма.
- В `REPORT.md` постановка, объяснения, блок-схема (Mermaid + PNG), таблица реальных результатов и выводы с проверкой статистической значимости.

Блок-схема `results/flowchart.png` уже включена в архив. При необходимости её можно пересоздать из `scripts/flowchart.dot` командой `dot -Tpng -Gdpi=170 scripts/flowchart.dot -o results/flowchart.png` (только для этого нужен установленный Graphviz).

**Ключевые эволюционные операторы написаны самостоятельно**, оптимизационные библиотеки не используются. NumPy — для численных операций и генерации случайных чисел, Matplotlib — для графиков, SciPy — для статистического t-теста.

Теоретический минимум: `f(1,1,1,1,1,1,1)=0`. Поиск эвристический, точное достижение теоретического минимума не гарантировано.
